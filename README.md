# CEO Personal OS

A private personal operating system for CEOs and founders.

**Single HTML file. No dependencies. No install. No build step.**

Open `ceo-os.html` in any browser and start using it immediately.

## What it includes

- Daily check-in (5 min)
- Weekly review (30 min)
- Quarterly review (2 hrs)
- Annual review (half day)
- 3 self-interviews: Past Year, Identity & Values, Future Self
- 4 frameworks: Annual Review (Gustin), Vivid Vision (Robbins), Life Costing (Ferriss), Life Map (Lieberman)
- Goal tracking: 1-year, 3-year, 10-year
- Principles, North Star, Memory

## Features

- Voice input on every prompt (Chrome/Edge)
- Auto-saves to browser localStorage
- Export all data as JSON
- Past entry navigation for all dated sections
- Works offline

## Usage

Download `ceo-os.html` and open it in Chrome or Edge. That's it.

## Built with

Vanilla HTML, CSS, and JavaScript. No frameworks. No dependencies. Intentionally.
